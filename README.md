# Game Alpi

## Project Overview
Game Alpi adalah platform mini game multiplayer berbasis web.

## Struktur Game

- /uno
  - Game kartu multiplayer UNO

- /werewolf
  - Social deduction game
  - Flow:
    Lobby → Room → Role Assignment → Game

- /impostor
  - Game deduksi multiplayer

- /catur
  - Game catur multiplayer

- /tebak-angka
  - Game puzzle sederhana

## Hosting

Frontend:
- Vercel

Backend:
- Supabase

## Development Notes

Project menggunakan struktur static frontend.
Folder game dipisahkan agar setiap game memiliki dunia dan UI sendiri.
